# Contributing guidelines

## Rule: every change goes through a branch + Pull Request
Any modification to this repository must follow the workflow below.

## Workflow
1. Create a new branch from `main` (one branch per change set).
2. Make the change(s) on that branch.
3. Open a Pull Request to `main`.
4. Request a review (at least one reviewer when possible).
5. Merge only after review (or after self-review if you are alone).

## Good practices
- Keep PRs small and focused.
- Use clear commit messages.
- Do not commit raw datasets or secrets.
